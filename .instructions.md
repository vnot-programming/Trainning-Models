## 📋 Global Rules (Always Applied)

### 1. Bio-Digital Minimalism 2026
**Wajib** untuk semua pembuatan antarmuka (HTML/CSS/JS/React/Vue):

- ✅ **Animations**: Hanya `transform` & `opacity` (60fps)
- ✅ **Typography**: Inter (body), Outfit (headings), Lora (serif)
- ✅ **Colors**: HSL palette, saturasi ≤20%, circadian-sync
- ✅ **Contrast**: WCAG 2.2+ (4.5:1 normal text, 3:1 large text)
- ✅ **Essentialism**: Tanpa ornamen tak berfungsi
- ✅ **Glassmorphism**: `backdrop-filter: blur()`, multi-layer shadows
- ✅ **Negative Space**: `clamp()` spacing, breathing room

Referensi lengkap: `.instructions/bio-digital-minimalism-2026.instructions.md`

### 2. Coding Standards
**Wajib** untuk semua kode Python/CUDA:

- **DRY** (Don't Repeat Yourself)
- **KISS** (Keep It Simple, Stupid)
- **Early Returns** (hindari nested if)
- **Single Responsibility** (setiap fungsi satu tanggung jawab)
- **Type Hints** untuk Python
- **Docstrings** untuk fungsi/classes

Referensi: `.agents/rules/coding-standards.md`

### 3. File Access Protection
**BACAA** file `.agentignore` sebelum membaca file apa pun.
File yang terdaftar di `.agentignore` **DILARANG** untuk diakses.

## 📂 Workspace Structure Awareness

Ketika bekerja di workspace ini, perhatikan:

2. **datasets/** - Dataset dari Roboflow, format YOLO & segmentation

## 🚀 Quick Commands

### Training
```bash
cd MyFineTunning-dev
python main.py --mode train --model yolo11m --data datasets/me-bottle-isempty-ku3-8/data.yaml
```

### Inference
```bash
python main.py --mode predict --weights models/yolo11m.pt --source data-files/test/images
```

### Pipeline
```bash
python run_pipeline.py --config config_shared.py
```
