Untuk membuat teks di dalam *file* `.sh` tetap menjadi komentar tetapi mudah di-copy-paste (tanpa ikut menyalin tanda `#`), Anda memiliki dua opsi terbaik.

Berikut adalah rekomendasinya:

### Opsi 1: Menggunakan Indentasi yang Rapi (Standar Bash)

Cara paling umum adalah memberikan jarak (indentasi) setelah tanda `#`. Dengan cara ini, Anda bisa dengan mudah memblok (highlight) teks mulai dari huruf `c` pada `cd` hingga akhir baris tanpa tidak sengaja membawa tanda `#`.

```bash
#!/usr/bin/env bash
# ==============================================================================
# setup.sh — Setup environment untuk MyFineTunning (RunPOD / GPU Server)
# ==============================================================================
#
# Cara pakai:
#
# 1. Background Execution via TMUX (Sangat Direkomendasikan untuk Cloud):
#    tmux new-session -d -s setup_session "cd /data/users/g6717500336/Trainning-Models/MyFineTunning-SlurmMaster && bash setup.sh 2>&1 | tee SetupReport.log"
#
# 2. Untuk memastikan skrip setup.sh berjalan dalam lingkungan slurm yang 
#    benar dan lingkungan Conda diaktifkan sebelum skrip dijalankan:
#
#    cd /data/users/g6717500336/Trainning-Models/MyFineTunning-SlurmMaster/utils
#    ./attach_gpu.sh
#
# ==============================================================================

```

### Opsi 2: Menggunakan Blok "Komentar Multi-Baris" (Paling Mudah Di-Copy)

Bash sebenarnya tidak memiliki fitur komentar multi-baris resmi seperti `/* ... */` di bahasa C. Namun, Anda bisa menggunakan trik *Null Command* (`:`) dipadukan dengan *Heredoc* (`<<`).

Dengan cara ini, Anda **tidak perlu menggunakan tanda `#` sama sekali** di setiap baris, sehingga Anda bisa melakukan klik tiga kali (triple-click) pada baris perintah untuk langsung meng-copy sebaris penuh dengan sangat mudah.

```bash
#!/usr/bin/env bash
# ==============================================================================
# setup.sh — Setup environment untuk MyFineTunning (RunPOD / GPU Server)
# ==============================================================================

: <<'CARA_PAKAI'

Cara pakai:

1. Background Execution via TMUX (Sangat Direkomendasikan untuk Cloud):
tmux new-session -d -s setup_session "cd /data/users/g6717500336/Trainning-Models/MyFineTunning-SlurmMaster && bash setup.sh 2>&1 | tee SetupReport.log"

2. Untuk memastikan skrip setup.sh berjalan dalam lingkungan slurm yang benar 
dan lingkungan Conda diaktifkan sebelum skrip dijalankan:

cd /data/users/g6717500336/Trainning-Models/MyFineTunning-SlurmMaster/utils
./attach_gpu.sh

CARA_PAKAI

# Skrip utama Anda dimulai di bawah ini
echo "Mulai menjalankan setup..."

```

**Rekomendasi:** Jika prioritas utamanya adalah kenyamanan *copy-paste* langsung dari terminal atau editor teks, **Opsi 2** adalah pilihan yang paling praktis. Sistem akan sepenuhnya mengabaikan teks apa pun yang berada di antara `: <<'CARA_PAKAI'` dan `CARA_PAKAI`.
