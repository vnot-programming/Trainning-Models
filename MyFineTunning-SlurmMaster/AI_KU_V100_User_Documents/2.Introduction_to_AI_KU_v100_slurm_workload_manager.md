# 2. Pengenalan AI_KU_V100 Slurm Workload Manager

Slurm adalah manajer sumber daya dan penjadwal tugas (job scheduler) yang dirancang untuk mengalokasikan sumber daya sesuai kebutuhan tugas pengguna. Slurm awalnya dibuat oleh Livermore Computing Center.

## Perintah Dasar Slurm

### 1. `sinfo`
Memberikan informasi mengenai sumber daya yang tersedia dari server.
Contoh:
```bash
[sorawid@slurmmaster ~]$ sinfo
PARTITION AVAIL  TIMELIMIT  NODES  STATE NODELIST
gpu*         up   infinite      2   idle ai[2-3]
```
- **Nama Partisi**: `gpu`
- Secara default, semua pengguna dapat mengirim tugas ke partisi ini tanpa QOS spesifik.

### 2. `squeue`
Memberikan informasi tentang tugas yang sedang berjalan dan sumber daya yang dialokasikan.
Contoh:
```bash
[sorawid@slurmmaster ~]# squeue -u root
             JOBID PARTITION     NAME     USER ST       TIME  NODES NODELIST(REASON)
                 8       gpu     bash     root  R       0:02      1 ai2
```
Output menunjukkan: JobID, Partisi, Nama Job, User, Status (ST), Waktu, Jumlah Node, dan Daftar Node.

### 3. `scancel`
Untuk membatalkan tugas, gunakan perintah:
```bash
scancel <JOBID>
```

### 4. `scontrol`
Melihat detail partisi:
```bash
scontrol show partition
```

### 5. `sacctmgr`
Mengelola akun dan melihat kuota (QOS).

#### 5.1 Melihat QOS User dan Default QOS
```bash
sacctmgr show assoc format=account,user%15,qos%30,defaultqos%20
```

#### 5.2 Melihat Detail Batasan QOS
```bash
sacctmgr show qos format=name%15,MaxTRESPU%35,MaxWall,MaxTRES,MaxJobsPU
```

| QoS Name | Max CPU (Cores) | Max RAM (GB) | Max GPU (unit) | Max Walltime |
| :--- | :--- | :--- | :--- | :--- |
| normal | 8 | 64 | 1 | Unlimited |

## Pengiriman Tugas Slurm (Job Submission)

### 1. `srun`
Digunakan untuk menjalankan tugas sederhana untuk pengujian.
```bash
srun -c 4 -p gpu hostname
```

### 2. Interactive Job
Menggunakan `srun` dengan parameter `--pty bash` untuk pekerjaan interaktif (biasanya untuk kompilasi program sebelum dijalankan via `sbatch`).
```bash
srun -c 4 -p gpu --gres=gpu:1 --pty bash
```

### 3. `sbatch`
Mengirim tugas menggunakan script shell.
| Directive | Description |
| :--- | :--- |
| `#SBATCH --job-name=test` | Job name |
| `#SBATCH --output=output%j.out` | Standard output and error log |
| `#SBATCH --ntasks=4` | Number Of tasks |
| `#SBATCH --time=00:01:00` | Time limit hrs:min:sec |
| `#SBATCH --cpus-per-task=1` | Number of cpu per tasks |
| `#SBATCH --gres=gpu:1` | Number of gres resources e.g. GPU |
| `#SBATCH --mem=16GB` | Job memory request to use in node |
| `#SBATCH --partition=gpu` | Partition Name |
| `#SBATCH --test-only` | For test submit job, not run job |

Contoh file `test.batch`:
```bash
#!/bin/bash
#SBATCH --gres=gpu:1
#SBATCH -p gpu
#SBATCH -c 4
hostname
nvidia-smi -L
```
Kirim dengan perintah:
```bash
sbatch test.batch
```
Cek hasil output:
```bash
cat slurm-<JOBID>.out
```
