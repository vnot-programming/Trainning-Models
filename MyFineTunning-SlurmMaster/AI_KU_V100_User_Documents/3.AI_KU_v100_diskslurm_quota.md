# 3. Kuota Disk & Slurm AI_KU_V100

Panduan mengenai batasan sumber daya (kuota) pada sistem Slurm.

## Kuota Slurm (QOS)

Setiap pengguna terikat pada batasan QOS `normal` sebagai berikut:

| No | Nama QoS | Max CPU (Cores) | Max RAM (GB) | Max GPU (unit) | Max Walltime |
| :-- | :--- | :--- | :--- | :--- | :--- |
| 1 | normal | 8 | 64 | 1 | Unlimited |

### Cara Mengecek Kuota Anda
Gunakan perintah berikut untuk melihat batasan QOS yang berlaku:
```bash
sacctmgr show qos format=name%15,MaxTRESPU%35,MaxWall,MaxTRES,MaxJobsPU
```

## Skenario Pengujian Kuota Slurm
Skenario ini menunjukkan bagaimana sistem menangani jika penggunaan melebihi batas (contoh pada limit CPU):

1. **Waktu 0:00**
   User `sorawid` mengirim tugas dengan 8 core CPU (batas maksimum).
   ```bash
   srun -c 8 sleep 600 &
   ```

2. **Waktu 1:00**
   User `sorawid` mencoba mengirim tugas tambahan dengan 1 core CPU.
   ```bash
   srun -c 1 sleep 60
   ```
   **Hasil**:
   ```text
   srun: job 69 queued and waiting for resources
   ```

**Penjelasan**:
JobID 69 tidak dapat berjalan dan masuk dalam antrean dengan alasan `QOSMaxCpuPerUserLimit`. Hal ini dikarenakan JobID sebelumnya sudah menggunakan seluruh kuota CPU yang tersedia untuk satu pengguna (8 core).
