# 1. Login Pertama AI_KU_V100
Panduan cara login ke cluster KU. Anda dapat mengubah kata sandi kapan saja.

## Cara Login ke Cluster KU
1. **Hubungkan VPN ke KU**
2. **Jalankan perintah SSH**:
   ```bash
   ssh <username>@158.108.222.131
   ```
3. **Masukkan kata sandi saat ini**: `Login@KU24`
4. **Masukkan kembali kata sandi saat ini**: `Login@KU24`
5. **Masukkan kata sandi baru Anda**
6. **Masukkan kembali kata sandi baru Anda**

## Mengubah Kata Sandi Kapan Saja
Jalankan perintah `passwd` untuk mengubah kata sandi Anda:
1. Masukkan kata sandi saat ini.
2. Masukkan kata sandi baru Anda.
3. Masukkan kembali kata sandi baru Anda.
