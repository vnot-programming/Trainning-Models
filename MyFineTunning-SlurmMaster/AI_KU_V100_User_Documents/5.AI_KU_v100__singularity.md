# 5. Panduan Penggunaan Singularity di AI_KU_V100

Singularity adalah sistem container yang dirancang untuk HPC (High-Performance Computing). Singularity mirip dengan Docker dan dapat menjalankan image dari Docker Hub.

## 5.1 Membuat Singularity Image dengan Fitur Fakeroot
Singularity memungkinkan Anda membangun image tanpa akses root menggunakan fitur `--fakeroot`.
Contoh file definisi (`.def`):
```text
Bootstrap: docker
From: pytorch/pytorch:latest

%post
    pip install datasets accelerate grad-cam captum 'transformers[torch]' opencv-python
    mkdir /data
    mkdir /work_scripts
```
Perintah untuk membangun image:
```bash
singularity build --fakeroot <nama_image>.sif <file_definisi>.def
```

## 5.2 Menarik (Pull) Container
Jika Anda ingin menggunakan image yang sudah ada dari repositori:
1. **NVIDIA GPU Cloud (NGC)**: [ngc.nvidia.com](https://ngc.nvidia.com)
2. **Docker Hub**: [hub.docker.com](https://hub.docker.com)

Perintah Pull:
```bash
singularity pull <nama_image>.sif docker://<url_container>
```

## 5.3 Menjalankan Container

### 5.3.1 Menjalankan Container Berbasis CPU
```bash
singularity exec <nama_image>.sif <perintah>
```

### 5.3.2 Menjalankan Container dengan Dukungan GPU
Selalu tambahkan flag `--nv` untuk mengaktifkan dukungan GPU NVIDIA di dalam container.
```bash
singularity exec --nv <nama_image>.sif <perintah>
# atau untuk masuk ke shell interaktif
singularity shell --nv <nama_image>.sif
```

## 5.4 Menjalankan Singularity melalui Slurm
Berikut adalah contoh script `sbatch` untuk menjalankan Singularity di cluster:
```bash
#!/bin/bash
#SBATCH -p gpu
#SBATCH -t 00:30:00
#SBATCH -J simple_job
#SBATCH -c 4
#SBATCH --mem=16G
#SBATCH --gres=gpu:1
#SBATCH --output=out%j.log

# Menampilkan informasi node dan GPU
hostname
nvidia-smi

# Menjalankan perintah di dalam Singularity container
singularity exec --nv /path/to/image.sif python script.py
```
