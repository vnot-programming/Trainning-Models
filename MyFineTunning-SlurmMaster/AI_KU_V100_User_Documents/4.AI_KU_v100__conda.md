# 4. Penggunaan Conda di AI_KU_V100

Panduan praktis pengelolaan environment Python menggunakan Conda dan integrasi dengan Jupyter Notebook.

## 1. Penggunaan Python dengan Conda

### 1.1 Inisialisasi Conda
Langkah pertama untuk mulai menggunakan Conda:
1. Jalankan perintah aktivasi:
   ```bash
   source /data/programs/anaconda3/bin/activate
   ```
2. Inisialisasi shell:
   ```bash
   conda init --all
   ```
3. **Logout** dan **Login** kembali agar perubahan diterapkan.

### 1.2 Membuat Virtual Environment
Gunakan perintah berikut untuk membuat environment baru:
```bash
conda create -n <nama_env> python=<versi>
```
Contoh membuat environment dengan Python 3.6:
```bash
conda create -n python3.6 python=3.6
```

### 1.3 Aktivasi Environment
```bash
conda activate <nama_env>
```

### 1.4 Instalasi Library
Setelah aktivasi, Anda bisa menginstal paket menggunakan `conda` atau `pip`:
```bash
conda install <nama_paket>
# atau
pip install <nama_paket>
```

### 1.5 Membuat Environment untuk Jupyter Notebook
Agar environment Conda muncul di pilihan Kernel Jupyter:
1. Aktivasi environment Anda.
2. Instal `ipykernel`:
   ```bash
   conda install ipykernel
   ```
3. Daftarkan kernel:
   ```bash
   python -m ipykernel install --user --name <nama_env> --display-name "Python (<nama_env>)"
   ```

### 1.6 Menghapus Virtual Environment
```bash
conda env remove -n <nama_env>
```

## 2. Menjalankan Jupyter Notebook via Slurm & SSH Tunnel

### 2.1 Menjalankan Job Jupyter
Gunakan `sbatch` untuk menjalankan Jupyter Notebook di node komputasi.
1. **Mulai Batch Job**: Buat script sbatch yang menjalankan `jupyter notebook --no-browser --port=<PORT>`.
2. **Setup SSH Tunnel**: Agar bisa diakses dari browser lokal.
   - **Mac/Linux**: `ssh -L <PORT_LOKAL>:localhost:<PORT_REMOTE> <user>@158.108.222.131`
   - **Windows**: Gunakan PuTTY atau PowerShell dengan perintah yang sama.
3. **Akses via Browser**: Buka `localhost:<PORT_LOKAL>` di browser Anda.
